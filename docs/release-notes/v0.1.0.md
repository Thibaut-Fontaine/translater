# v0.1.0 — software preview

Offline bidirectional voice translator for the Raspberry Pi 5:
Whisper.cpp (speech in) → NLLB-200 (translation) → Piper (speech out), three
physical buttons, no screen, no network.

> **Status: software complete, hardware not yet validated.** The full chain
> passes `xtransd --selftest` on x86 and on arm64 under QEMU, and the SD image
> builds and verifies (14 checks). Nothing has booted on a Pi yet, and the 1.6 s
> latency target is unproven.

## Assets

| Asset | What it is |
| --- | --- |
| `xtrans-arm64-container-v0.1.0.tar` | `docker load -i` this; contains `xtransd`, Piper, espeak-ng data. Models are **not** included. |
| `xtrans-install-v0.1.0-linux-x86_64` | SD flasher: refuses fixed/mounted/too-small targets, writes, verifies byte for byte. `--dry-run` runs the checks only. |
| `SHA256SUMS` | Digests of the assets above. |

The **6 GB SD image is not attached**: GitHub caps release assets at 2 GB. It is
reproducible from this tag:

```bash
git clone https://github.com/Thibaut-Fontaine/translater.git
cd translater && git checkout v0.1.0
scripts/fetch_third_party.sh      # whisper.cpp + Piper (pinned commits)
scripts/fetch_models.sh           # NLLB int8 + whisper + fr/en voices (~1.6 GB)
./scripts/docker.sh image         # cross-builds xtrans:arm64 (no QEMU needed)
./scripts/build_image.sh          # 6 GB image, no root, no loop devices
./build/xtrans-install --image build/image/xtrans.img --device sdb
```

Then: card in the Pi, battery, listen for **"Prêt."**

## What works

- Language table, turn state machine, lock-free audio ring, VAD gate — unit tested.
- Whisper.cpp STT, NLLB-200 int8 with KV cache, Piper TTS, full-chain selftest.
- en→fr and fr→en match the reference implementation on the same ONNX files.
- Arm64 container: builds cross-architecture and passes the selftest emulated.
- SD image builder: grows the partition and writes the payload via
  `e2fsck`/`resize2fs`/`debugfs` in a container — no root, no loop devices.

## Known limits

- **Never run on a Raspberry Pi.** ALSA capture/playback and GPIO buttons are
  compiled but unexercised; button bounce and audio levels are guesses.
- **Latency**: 550–730 ms per NLLB decoder step on the development host. The Pi
  measurement decides whether CTranslate2 replaces ONNX Runtime for MT or whether
  Whisper must drop to `tiny`/`audio_ctx`.
- **Thai** has STT and MT, but its only Piper voice needs a Piper ≥ 1.9 Thai
  frontend: no speech output today.
- **Hmong and Yunnan minority languages**: no model coverage (see
  `docs/language-matrix.md`). Only Tibetan, Jingpho and Shan exist in NLLB.
- The 6 GB image is not grown to the card on first boot.
